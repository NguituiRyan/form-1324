# FORM / 1324

A visual workout planning experience powered by the
[hasaneyldrm/exercises-dataset](https://github.com/hasaneyldrm/exercises-dataset).

## What it does

- Offers four working ready-made training plans
- Searches and filters 1,324 exercises
- Shows target muscles, equipment, and step-by-step technique
- Builds and saves custom plans in the browser
- Tracks completed movements on the current device
- Adapts to desktop, tablet, and mobile

## Run locally

```bash
npm install
npm run dev
```

Production check:

```bash
npm run build
```

## Dataset and media

Exercise names, categories, muscles, equipment, and English instructions are
derived from `hasaneyldrm/exercises-dataset` and used under its MIT license.
The source repository's images and animations have separate Gym visual terms
and are intentionally not redistributed here. FORM / 1324 uses original
code-native muscle maps instead.
